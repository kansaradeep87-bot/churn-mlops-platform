# Customer Churn Prediction & MLOps Platform

A machine learning project that predicts customer churn using Python, scikit-learn, and FastAPI.

## Project Overview

Customer churn occurs when customers stop using a company's services. This project uses customer information to predict whether a customer is likely to churn.

The project currently includes a machine learning training pipeline, a prediction script, a REST API, and automated tests.

## Features

- Customer churn prediction using Logistic Regression
- Data preprocessing with pandas and scikit-learn
- Feature scaling and categorical encoding
- FastAPI REST API for predictions
- Churn probability returned as a percentage
- Automated endpoint tests using pytest

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/kansaradeep87-bot/churn-mlops-platform.git
cd churn-mlops-platform
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

Activate it on Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```bash
python -m pip install pandas scikit-learn joblib fastapi uvicorn pytest httpx
```

### 4. Train the model

Make sure the dataset is available at the path expected by `train.py`, then run:

```bash
python train.py
```

This trains the model and saves `churn_model.pkl`.

### 5. Run the prediction API

```bash
python -m uvicorn app:app --reload
```

Open the interactive API documentation:

http://127.0.0.1:8000/docs

Use the `/predict` endpoint to submit customer information.

### 6. Run automated tests

```bash
python -m pytest test_app.py -v
```
